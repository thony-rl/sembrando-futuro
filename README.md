#  🌱 EcoMacetas Medicinales

Landing page ecológica para el proyecto comunitario **EcoMacetas Medicinales**, enfocado en la transformación de botellas y envases de plástico reciclado en macetas para el cultivo de plantas medicinales y aromáticas.

---

## 🚀 Características

- **Diseño Responsive:** Adaptado para dispositivos móviles, tablets y escritorio.
- **Acceso Rápido a Recursos:** Enlaces directos a la comunidad de Facebook y carpetas de evidencias en Google Drive.
- **Catálogo Interactivo:** Información sobre plantas medicinales (Menta, Sábila, Romero, Hierbabuena).
- **Formulario de Contacto Interactivo:** Confirmación de envío mediante modal animado sin recarga de página.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica.
- **CSS3:** Estilos personalizados, variables CSS, Flexbox/Grid y animaciones.
- **JavaScript (Vanilla):** Manejo de eventos del formulario y modal de confirmación.
